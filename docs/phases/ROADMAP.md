## Gates

- **MVP GA (end of week 8, §14.1):** self-serve signup → Stripe trial → onboarding → import → routing → work leads → convert → Kanban → close → basic reports and dashboards, all in production (eu-central-1). §11.1 budgets met at the 800-rep seed with 500k leads. Zero critical/serious axe violations. RLS audit and cross-tenant suite green. External auth/tenancy review with no open high findings. Demo tenants ready.
- **v1 GA (end of week 26, §14.2):** all §2.1 modules shipped; full-scale load test (§11.2) passes; pen test has no open critical/high findings; two cells live; backup-restore drill passed; public docs site and API reference; runbooks complete.
