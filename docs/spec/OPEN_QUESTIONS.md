# Open questions for the owner (kick-off review of MASTER_SPEC v1.0)

Raised under §0.1 step 5. When a question is answered, record the answer here. If it changes the spec,
also log it in `CHANGELOG_SPEC.md`. **(Blocks Pxx)** marks the phase that cannot finish planning until the question is answered.

## Contradictions

1. **Trial plan.** §7.20a says "14-day trial of the *top* plan", but §12.2 says "14-day trial of *Business*". The top plan is Enterprise. Proposal: trial Business. **(Blocks P05)**
2. **Control plane vs "tenant data never leaves its cell".** §3.4 puts global `user-email → tenant` routing (`cp_user_routing`) and Stripe customer data in the control plane. Both are personal data. Proposal: store only a keyed hash of the email (HMAC) in the control plane and let the cell hold the address, then document Stripe as a global sub-processor in the residency ADR. **(Blocks P00)**
3. **Staging platform.** #25 allows Railway for staging, but §13.5 `deploy-staging.yml` targets ECR/ECS. Proposal: staging on AWS ECS so it mirrors prod, and drop Railway. **(Blocks P00)**
4. **Pack contents.** #36 says "CLAUDE.md + repo scaffold supplied", and §3.3 points to `REPO_SCAFFOLD.md`. Neither was included. CLAUDE.md has been derived from §0/§3/§13. Do you have the scaffold file, or should P00 derive it from §3.3? **(Blocks P00)**
5. **Contrast rule vs tokens.** §9.2 requires every text/background pair to be ≥ 4.5:1. `--text-disabled` (graphite-400 on white = 2.58:1; dark #525A66 on #14181E = 2.56:1) fails, and so does "Lost = graphite-400" if it is used as text. Proposal: exempt disabled text from the contrast test (WCAG does too), and render Lost chips with graphite-600 text on a graphite-100 background. **(Blocks P00)**
6. **MVP performance scale.** The §11.1 budgets are "measured … with 5M leads", but the MVP gate (§14.1) says "800-rep seed with 500k leads". Proposal: 500k for the MVP gate and 5M for the v1 gate. **(Blocks P05)**
7. **Process vs this environment.** §0.2 and §13.2 prescribe `feat/Pxx-<slug>` branches, `gh pr create` and self-merge. Cloud sessions here run on an assigned branch (`claude/…`), and PRs are opened through the GitHub integration, not the `gh` CLI. Do you want one PR per task from task branches, or phase work on the session branch? Is self-merge after green CI still OK?

## Gaps and ambiguities

8. **Licences outside MIT/Apache/BSD/ISC (§0.3).** Inter, JetBrains Mono and IBM Plex Sans Arabic are OFL-1.1. MinIO is AGPL (local dev only). ClamAV is GPL (separate process). Redis 7.4+ is RSAL/SSPL, and Redis 8 is AGPL. Proposal: approve the OFL fonts, use MinIO and ClamAV as out-of-process dev/infra tools only, and use **Valkey** locally with ElastiCache (Valkey or Redis OSS engine) in AWS. Please approve. **(Blocks P00)**
9. **Paid sub-processors.** Stripe, Twilio, Meta, Voyage, Deepgram, SES/Postmark, Sentry, Anthropic, Xero/QBO and Cloudflare Turnstile are named in the spec. Can I treat spec-named services as pre-approved under §0.3, with fakes only until you provide test-mode keys?
10. **Contact sharing under `CONTROLLED_BY_PARENT`.** Contacts can relate to several accounts (`account_contact_relation`) and can exist without an account. Which account controls access, and who sees orphan contacts? Proposal: the primary account controls access, and orphan contacts fall back to owner + hierarchy. **(Blocks P01)**
11. **Custom-field indexes at scale.** `CREATE INDEX CONCURRENTLY` cannot run on a partitioned parent in PG16, and per-tenant partial expression indexes × 2,000 tenants × fields means tens of thousands of indexes per cell. Proposal: build indexes per partition, keep a strict per-plan cap, and move heavy tenants to typed "promoted columns" or OpenSearch. OK to decide this in the P02 plan?
12. **Partitioned tables vs PK rule.** Postgres requires the partition key in every PK/unique constraint, so `activity` (monthly by `created_at`) gets PK `(tenant_id, created_at, id)`. FKs into activity therefore need `created_at` too, or no FK at all (logical references plus integrity jobs). Is that acceptable? (It does not change tenancy; I'm flagging it.)
13. **Corporate-currency conversion date.** Is `amount_corporate` converted at the rate on the close date (Salesforce "advanced currency management"), or at the record's create/update date? Proposal: close date for opportunities and transaction date otherwise. Recalculate on close-date change? **(Blocks P02)**
14. **MVP report widgets.** M13 says "6 widget types" and P05 says "6 chart types". Which six? Proposal: bar, line, donut, funnel, KPI tile, table.
15. **Hash-chained audit concurrency.** A strictly linear per-tenant chain serialises every write in a tenant, which conflicts with bulk imports at ≥ 2,000 rows/s. Proposal: per-tenant chains that append in short micro-batches (a Merkle root per batch). The chain stays verifiable without a hot row lock. Since this touches the audit-log design, it needs your approval. **(Blocks P01)**
16. **GCC telephony.** UAE (and at times other GCC markets) restrict VoIP/WebRTC calling. Twilio's WebRTC softphone may not be usable for UAE-based agents. Should P06 plan a SIP/local-carrier adapter (e.g. 3CX or a UAE carrier) as a v1 requirement for the Aurelia-style floors?
17. **Residency of sub-processors in me-central-1.** SES inbound receiving, Deepgram, Voyage, and Anthropic regional processing are not available in every AWS region. Should AI, speech and email-to-lead be disabled by default for tenants that pick strict residency, with a documented cross-border transfer notice otherwise?
18. **External approval lead times.** Gmail restricted scopes need Google verification plus a CASA security assessment (weeks, and a paid assessor). Meta WhatsApp Embedded Signup needs Tech Provider approval. Microsoft needs publisher verification. These should start in parallel now. Who owns the developer accounts?
19. **Domains and accounts.** Is `salesmaker.app` owned? Which AWS organisation, Vercel team and Stripe account should be used, and when will test-mode keys be available?
20. **Opportunity sharing default.** §6.3 lists "Opportunity→Account optional" for controlled-by-parent, but the default is PRIVATE. Confirm that PRIVATE plus the account-team extension is the intended default.
21. **Flat-pricing user caps.** §12.1 asks you to confirm the per-plan user caps (25/150/500/1,000+) and whether the MVP has a free tier or only a trial. **(Blocks P05)**
